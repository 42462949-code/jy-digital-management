佳洋 · 生产看板 PDF 微信报表助手（Windows 安装包，需本机完成测试）

一、安装
1. Windows 10/11：先把整个 ZIP 解压到一个文件夹。
2. 双击 Install.cmd，不需要以管理员身份运行。
3. 首次安装需联网，安装 Python、浏览器及依赖，可能需要几分钟。
   若没有 winget（应用安装程序），请先从 python.org 安装当前用户版 Python 3.13，再运行 Install.cmd。
4. 安装完成后打开配置窗口；以后双击桌面 Jiayang Report 快捷方式。
   程序安装在 %LOCALAPPDATA%\JiayangReport。

二、自行设置（账号和时间都可以修改）
1. 每日越南时间：24 小时制 HH:MM，初始 00:17。
   固定使用越南 UTC+7，不依赖电脑当前时区；请保持 Windows 系统时钟准确。
2. 收件人：填写个人微信账号，一行一个。初始为空，需要您自己填写。
   要发送给之前指定的两位，请把他们的微信账号各填一行。
3. 管理系统用户名、密码：用于专用工作台登录。
   密码使用 Windows 凭据管理器保存，不写入配置 JSON。
4. 点击“保存设置”。修改后会先暂停旧定时任务，最后需要再次点击启用。

三、非常重要：生产数据来源
本系统现在把数据保存在各浏览器本地，并没有跨浏览器共享数据库。
此助手创建独立的“专用工作台”浏览器，不能自动读取您日常 Edge/Chrome 的本地数据。
点击“打开专用工作台”，在里面登录、核对和导入最新生产报表。
以后请在这个专用工作台维护需要定时导出的数据；其他浏览器更新不会自动同步。
新浏览器的本地登录密码也独立；如果普通浏览器改过密码，不会自动带到这里。
首次新浏览器可使用网站原始登录信息，登录后可在专用工作台修改密码，并同步更新助手密码。
查看专用工作台的“生产数据看板”，核对无误后关闭浏览器窗口。
再勾选“已核对最新生产数据”，保存，点“预览 PDF”检查生成内容。
报表包含当前工作台的生产统计及最近七个生产日趋势，与网页版看板逻辑相同，
不是自动只统计前一天；PDF 标明越南生成时间。空数据停止发送。
生成 PDF 时需要独占专用浏览器数据目录，请在定时前关闭专用工作台。

四、微信校准及一次真实测试（每个联系人单独完成）
1. 登录一个 Windows 微信主窗口。请选择稳定分辨率、缩放和显示器。
2. 配置窗口选择某个收件人，点击“校准所选联系人”。
3. 程序搜索您填写的账号。您必须人工核对结果确实属于该账号。
4. 按提示框选：对应搜索结果行、已打开聊天的标题、最下方消息编辑区、发送按钮。
   校准截图保存在本机，不上传；标题和搜索行要包含头像/名称等稳定唯一信息。
5. 点击“测试发送给所选联系人”。这会实际发送当前看板 PDF。
6. 程序核对搜索行、聊天标题和编辑区里的 PDF 文件名后才点击发送。
   如果微信没有向 Windows UI Automation 暴露编辑区或文件名，会停止。
   可检查微信是否提供辅助功能/读屏兼容设置；没有该能力的微信版本不能使用本包自动发送。
   不会用盲点坐标来绕过文件名验证。
7. 请在微信里人工检查收件人、PDF 内容及发送结果，并确认测试通过。
8. 每位收件人测试通过、PDF 内容确认无误后，才允许“启用定时”。
   本包不是针对某一个微信版本保证可用；本机测试不通过时不要启用。

五、定时运行及限制
Windows 任务计划程序中的任务名：Jiayang-WeChat-PDF。
每天指定的越南时间触发，仅在当前 Windows 用户已登录时运行。
必须开机、不休眠、不锁屏，微信已登录，网络正常。
任务执行期间不要操作键鼠、切换窗口；避免通知、弹窗遮挡。
屏幕左上角是 PyAutoGUI 紧急停止位置；失败后先人工检查微信草稿。
未按时运行不会补发；错过两分钟窗口会跳过。
任务不会自动唤醒电脑。个人微信不提供官方定时发送接口，不保证精确送达时间。
发送点击前写入每日每个账号的防重记录；点击后结果不确定也不自动重试。
日志里的 send_clicked 仅代表已点击发送并观察到附件离开编辑区，不证明对方收到。
发送失败会记录日志和当前屏幕截图，可能包含工作台/微信内容，请只保存在自己的电脑。
更改微信版本、主题、分辨率、缩放、昵称、头像或窗口布局后，重新校准和测试。

六、暂停、日志和数据
配置窗口点击“暂停定时”会删除任务计划，不删除业务数据。
“查看日志 / PDF”打开安装目录：reports 为 PDF，logs 为日志及失败截图。
config.json 为设置，calibration 为联系人校准截图，browser-profile 为专用浏览器数据，
delivery.sqlite 为防重记录。上述内容仅保存于您的 Windows 账号。
如需卸载，先暂停任务，再删除桌面快捷方式。需要保留数据时先备份上述目录，
然后删除 %LOCALAPPDATA%\JiayangReport 文件夹。
